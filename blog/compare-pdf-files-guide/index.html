How to Compare Two PDF Versions (Step-by-Step Guide) — DSUTILITY

When a contract, policy, application form, circular or report is revised, reading both PDFs from beginning to end can make small changes easy to miss. A page-by-page text comparison helps you find pages that need a closer review.

What a PDF comparison can and cannot tell you

PDF Compare extracts selectable text from both documents and compares corresponding page positions. It reports unchanged, changed, added and removed pages and lets you save a text report. It does not detect visual-only changes such as font, spacing, signature, image, colour or exact layout shifts. Scanned PDFs without a text layer need OCR first.

Step-by-step workflow

  1. Keep the earlier file as Original and the newer file as Revised.
  2. Select both PDFs and run the comparison.
  3. Review pages marked changed, added or removed. Compare names, dates, amounts, clauses and page numbering carefully.
  4. Download the report for a review trail, then open the source PDFs side by side for important decisions.

Why a page may be marked changed

Even a small wording change can mark a page as changed. Conversely, text extraction order may vary in tables or multi-column layouts. A changed page is a review signal, not a legal conclusion. If page counts differ, the tool compares matching page positions and marks extra pages as added or removed.

How to compare scanned PDFs

Scanned PDFs may contain page images rather than selectable text. Use OCR PDF to create a searchable text layer first, then verify the OCR output because recognition can confuse names, numbers and punctuation.

Privacy and limitations

Text extraction runs in your browser; this tool does not send PDF files to a DSUTILITY PDF-processing server. The PDF.js library is loaded from a public CDN when comparison starts. Large files may use substantial browser memory, so each input is limited to 100 MB. Password-protected or damaged files may not open.

FAQ

Does it compare layout or signatures?

No. This version compares extractable text and page positions, not pixel-level appearance, signatures or images.

Can it compare contracts?

It can help flag pages with text changes, but it is not legal advice. Review source documents carefully before relying on a result.

What if both PDFs look different but text is the same?

Visual-only changes may not be reported. Use a visual comparison workflow for exact appearance changes.

Can I export the result?

Yes. Download a text report of changed, added and removed pages.
