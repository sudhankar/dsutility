What this checker can verify

It can compare the actual file against minimum or maximum pixel dimensions, exact dimensions, file-size limits, allowed image formats and an aspect-ratio rule. A failed check means the current file does not meet the requirement you entered; it does not tell you what the destination portal will accept beyond those rules.

Why this is different from image editing tools

Image Resize & Compress is for changing an image. Smart Image Compressor is for reducing file size toward a target KB. Job Application Photo Maker prepares a photo using an application workflow. This page is intentionally a validation step: check first, edit only if necessary.

FAQ

Does a pass guarantee the website will accept my image?

No. It only confirms the rules you entered. A destination may have additional requirements such as background, face position, naming or hidden validation.

Should I enter the rules from the current application form?

Yes. Requirements vary between portals and applications. Use the current destination instructions rather than a generic online value.

Does this tool resize or compress the image?

No. It is a checker. Use a suitable image preparation tool after identifying a failed requirement.

What does aspect-ratio tolerance mean?

It allows a small difference between the image's actual width-to-height ratio and the ratio you entered. A lower tolerance is stricter.
