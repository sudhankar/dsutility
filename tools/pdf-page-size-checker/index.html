What this tool does

PDF Page Size Checker shows the physical page dimensions stored in a PDF. This is useful when a document contains A4 pages mixed with Letter, Legal, scanned pages or landscape sheets and you need to confirm the layout before printing or submitting it.

How to check PDF page size

  1. Choose or drop your PDF.
  2. Wait for the browser to read the document.
  3. Review each page's dimensions in points and approximate millimetres.
  4. Check the orientation column for portrait, landscape or square pages.

Limitations and honest expectations

  • The tool reports the PDF page box size; it does not change the page dimensions.
  • Millimetre values are approximate because PDF dimensions are stored in points.
  • Very large or damaged PDFs may take longer to read or may fail to open.

Privacy

The selected PDF is read in your browser. It is not uploaded to a DSUTILITY PDF-processing server for this check.

Frequently asked questions

Can one PDF contain different page sizes?

Yes. Each page can have its own dimensions and orientation. The table makes those differences easy to spot.

Does this change my PDF?

No. This is a read-only inspection tool and does not modify your original file.

Can I check A4 versus Letter pages?

Yes. The point and millimetre measurements help you identify common paper sizes and unusual page dimensions.
