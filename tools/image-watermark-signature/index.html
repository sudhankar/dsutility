What this tool is for

Add a name, office label, reference note or visible signature to an image or scan before sharing it. Unlike a fixed-position watermark, the overlay can be moved and resized through the controls.

How to use it

  1. Select the base image.
  2. Enter a text watermark and adjust opacity, size and colour.
  3. Use horizontal/vertical controls or the nudge buttons to move the text.
  4. Add a signature image and adjust its position and width.
  5. Review the preview and download the final image.

Privacy and limitations

Processing happens locally in the browser. The visible signature is an image overlay; it is not a cryptographic or legally certified digital signature.

FAQ

Can I move the text?

Yes. Use the position controls or the arrow nudge buttons.

Can I resize the signature?

Yes. Signature width and position are adjustable.
