What this tool does

This tool creates a separate photo with a selected aspect ratio and pixel dimensions. It uses a canvas in your browser, so the original image is not sent to a DSUTILITY processing server.

How to use it

  1. Select a clear JPG, PNG or WebP photograph.
  2. Choose a common ratio or enter your own ratio.
  3. Set the output dimensions required by the destination form, application or printer.
  4. Adjust horizontal and vertical focus so the crop keeps the important part of the photograph.
  5. Choose whether to keep the original background or attempt connected-background removal, review the preview and download the result.

Important limitations

  • This tool does not certify that a photograph meets the rules of a particular passport office, visa authority, examination board or government form.
  • Photo dimensions and background rules vary by destination. Always check the current instructions of the organization receiving the image.
  • The optional background-removal pass attempts to make connected plain backgrounds transparent. Complex, patterned or low-contrast backgrounds may need the dedicated Background Remover tool.
  • Exact print dimensions also depend on printer and print settings. Pixel dimensions are what this browser tool controls.
  • Very large source images can use significant browser memory, especially on phones.

Privacy

The selected photograph is decoded and processed locally in the browser. This tool does not require an image upload to a DSUTILITY processing server.

Frequently asked questions

Is this an official passport photo generator?

No. It is a general-purpose photo preparation tool. Always follow the current specifications published by the authority or organization that will receive the photograph.

Can I create a 35 × 45 mm style photo?

Yes. The tool includes a 7:9 aspect-ratio preset and a 413 × 531 pixel starting size. You can change the pixel dimensions if the destination specifies another size.

Can it remove a background?

The optional background-removal pass is designed for common plain backgrounds. It is not a professional segmentation model, so complex backgrounds may require the dedicated Background Remover tool.

Is my photograph uploaded?

No. Processing is performed in your browser for this tool.
