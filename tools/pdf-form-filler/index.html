Supported fields

  • Text boxes, including multiline text fields
  • Checkboxes
  • Dropdown lists and radio choices

!

Technical limitations

  • Only existing interactive form fields are supported.
  • Flat forms, scanned forms, XFA forms and signature widgets may not be fillable here.
  • Some unusual fonts or non-Latin characters may not be supported by the PDF’s default form font; check the saved output.
  • Password-protected, damaged or very large PDFs may fail to open.

Frequently asked questions

How is this different from PDF Editor?

PDF Form Filler detects actual interactive form fields already embedded in a PDF. PDF Editor is for placing text, shapes, images and signatures freely over a page, including many flat documents.

Can I fill a scanned application form?

Not as interactive fields. OCR can recognize text but does not automatically create fillable fields. For a flat form, use PDF Editor to place text or a signature where needed.

Are my documents uploaded?

This tool processes the selected PDF in your browser and does not send it to a DSUTILITY PDF-processing server. The PDF library is loaded from a public CDN when you ask to detect fields.

Will the result work in every PDF viewer?

Common AcroForm fields are supported, but PDF viewers can differ in how they display fonts and form appearances. Open the downloaded file and verify all values before submitting it.
