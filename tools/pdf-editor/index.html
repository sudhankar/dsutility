About PDF Editor

PDF Editor is a browser-based workspace for adding text, images, shapes, freehand marks, highlights, redactions, signatures, and other visual annotations to a PDF. It is designed for practical page-level editing while keeping the original file available until you choose to export.

How to use PDF Editor

  1. Open or drop a PDF into the editor.
  2. Choose the editing tool you need, such as Text, Image, Shape, Draw, Mark, or Sign.
  3. Click or drag on the page and adjust the available properties such as size, color, opacity, or thickness.
  4. Review every edited page at normal zoom and correct any misplaced elements.
  5. Choose Save PDF, select the required save option, and export the edited document.
  6. Reopen the saved PDF in a separate viewer to confirm the final appearance.

Technical limitations

  • This is a visual PDF editor, not a full desktop publishing application.
  • Complex interactive forms, embedded media, advanced PDF objects, and some document structures may not be editable.
  • Visual redaction must be verified carefully; a rectangle that only covers text is not automatically secure removal of the underlying content.
  • Very large PDFs can use considerable browser memory during rendering and export.

Frequently asked

Can I add text and shapes?

Yes. The editor provides text, image, shape, drawing, and annotation controls for page-level changes.

Can I sign a PDF?

Yes. You can create and place a visual signature. This is different from a cryptographic digital certificate signature.

Does the editor upload my PDF?

The supported editor workflow is designed for browser-side processing, so the source PDF does not need to be sent to a DSUTILITY editing server.

Why should I reopen the saved PDF?

Reopening the exported file verifies that page positions, text, images, drawings, and signatures look as expected outside the editor.

Privacy

The editor is designed to process supported PDFs in the browser. The source file does not need to be uploaded to a DSUTILITY editing server. Browser memory, temporary rendering data, and downloaded files remain under the user’s device control. For confidential documents, use a trusted device and verify the exported copy before sharing.
