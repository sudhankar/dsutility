Technical limitations

  • Does not compare images, signatures, fonts, colors or layout.
  • Scanned PDFs need OCR before comparison.
  • Tables and multi-column pages may extract in a different text order.
  • Large or damaged PDFs can use substantial memory or fail to open.
  • Check important legal, financial or official changes in the source files.

Frequently asked questions

Can I compare scanned PDFs automatically?

This version compares selectable text and does not run OCR automatically. For a scanned PDF, use OCR PDF first, check the recognized text, and then compare the searchable PDFs. Keeping OCR separate avoids downloading a large recognition engine for every visitor and keeps normal comparisons lighter.

Are my PDFs uploaded?

The selected PDF files are read and processed in your browser; they are not sent to a DSUTILITY PDF-processing server by this tool. The PDF.js library is fetched from a public CDN when you start comparing. Your browser and network provider may still handle ordinary page and library requests.

Does it show exact visual differences?

No. It compares extracted text by page position and reports page-count differences. It does not detect changes to images, signatures, formatting or pixel-level appearance.

Can I save the results?

Yes. Download a plain-text report listing pages marked changed, added or removed, including extracted text previews for those pages.

Privacy

PDF Compare reads and compares the selected files in your browser; this tool does not upload them to a DSUTILITY PDF-processing server. The PDF.js library is loaded from a public CDN after you start the comparison, so an internet connection is needed to load that library. Processing speed and memory use depend on your device and file size. For sensitive documents, review your organization’s document-handling requirements before using any online tool.
