What makes this compressor different?

DSUTILITY already has an Image Resize & Compress tool for hands-on dimension changes, crop ratios and quality controls. This page is deliberately narrower: it starts with the file-size requirement and automates the compression search across multiple images. It is useful when an application, email workflow or upload form says something such as “maximum 100 KB” and you have several files to prepare.

It does not create passport dimensions, application-photo presets or signatures. For those jobs, use the Passport Photo & ID Photo Maker or Online Form Photo & Signature Maker.

How the target-size workflow works

  1. Select the images that need the same general size rule.
  2. Enter the maximum KB limit required by the destination.
  3. Choose JPG or WebP for the most flexible target-size compression.
  4. Optionally set a maximum long side if very large originals are unnecessary.
  5. Start compression and review the actual final KB, dimensions and savings for every file.
  6. Download individual results or package all successful results into one ZIP.

The reported size is the actual generated Blob size, not an estimate based on a quality number. When the selected limit cannot be reached without extreme degradation, the result reports that honestly instead of claiming an exact target.

Common use cases

  • Reducing several photographs below an email or upload limit.
  • Preparing website images when a byte budget matters more than a fixed dimension.
  • Compressing a folder of photos for easier sharing.
  • Creating smaller JPG/WebP copies while keeping the original files untouched.

Frequently asked questions

Can it make every image exactly 50 KB?

No. A byte-perfect target is not always possible because image encoders work in discrete steps and different images compress differently. The tool aims for the selected maximum and reports the actual result.

Will my original images be changed?

No. The selected originals are read by the browser and new output files are generated. Your source files remain unchanged on your device.

Which format is best for photographs?

JPG is widely compatible and works well for ordinary photographs. WebP can be smaller when the receiving system accepts it. PNG is better suited to lossless graphics and transparency, but it is often inefficient for photographs.

What if the target KB is too small?

The tool may reduce dimensions after quality adjustments, but it will not promise an impossible result. If the final file is still above the limit, use a larger target or confirm whether the destination actually requires that limit.
