PDF Metadata Editor

View and edit the hidden information inside your PDF — title, author, subject, keywords, creator, producer, and dates.

🔒 Processed locally in your browser.

Drop a PDF here or click to select

How to edit PDF metadata

  1. Drop your PDF into the box above.
  2. Current metadata is loaded into the fields.
  3. Edit any field — title, author, subject, keywords, creator, producer, dates.
  4. Click Save with new metadata.

Technical limitations

  • Only the standard document information dictionary is edited. XMP metadata streams may retain older values.
  • Date fields accept ISO 8601 format (e.g., 2026-05-14T12:00:00Z) or plain dates.
  • Some reader apps cache metadata; you may need to close and reopen the file to see changes.

Frequently asked

What metadata exists in a PDF?

Common fields: title, author, subject, keywords, creator (app that made it), producer (library that wrote the PDF), and creation/modification dates.

Should I clear metadata before sharing?

Yes — author and creator fields often contain your computer username or real name. Clearing them is a good privacy step.

Does clearing metadata shrink the file?

Slightly, but not enough to matter. Use Compress PDF for real size reduction.
