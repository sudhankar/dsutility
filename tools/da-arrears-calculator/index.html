How this DA arrears calculator works

Select the first and last month, enter the Due DA percentage and Drawn DA percentage, then add employees. For each employee, the calculator creates one column for every selected month and calculates the DA difference from the entered Basic Pay.

Monthly DA arrear = Basic Pay × (Due DA − Drawn DA) ÷ 100. The employee's monthly amounts are added to Total Arrear. A default deduction is then applied according to the selected GPF, NPS or UPS type, but the amount remains editable.

GPF, NPS and UPS deduction handling

GPF

Default deduction is 100% of the calculated arrear. This is editable because departmental practice may provide for a different amount to be credited to GPF.

NPS

Default deduction is 10% of the calculated arrear in this calculator, following the requested office-calculation workflow. The deduction amount is editable.

UPS

Default deduction is 10% of the calculated arrear in this calculator. Applicable UPS/departmental rules should be verified before an official payment statement is issued.

Useful for office arrear statements

The table is intentionally designed like a departmental statement: employee identity columns stay at the left, month-wise amounts follow the selected period, and Total Arrear, Deduction and Net Payable appear at the right. On smaller screens the table remains horizontally scrollable rather than shrinking the figures into an unusable layout.

Frequently asked questions

Can I add many employees?

Yes. Use Add Employee to create additional rows. Each employee has an independent GPF/NPS/UPS selection and editable deduction.

Can I change the deduction amount?

Yes. The default amount is only a starting value. You can edit it directly in the table before pressing Calculate Arrear.

What if Basic Pay changes during the selected period?

This version uses one Basic Pay per employee for the selected period. For an official calculation where Basic Pay changes, split the calculation into separate periods or use a future advanced pay-change mode rather than silently applying the wrong pay to every month.

Can I save the result as PDF?

Yes. Print / Save as PDF opens the browser's print dialog with a print-optimized statement. You can choose “Save as PDF” in the browser.
