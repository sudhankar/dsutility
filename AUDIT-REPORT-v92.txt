DSUTILITY v92 — RELEASE AUDIT
=============================
Baseline: DSUTILITY-v91-FINAL.zip
Scope: defect remediation only; no new tool added; Advanced Grammar Checker remains removed from source.

REMEDIATIONS
------------
1. Service Worker cache bumped from dsutility-v83 to dsutility-v92 to invalidate stale cached HTML/assets after deployment.
2. Normalized every HTML page to exactly one <!DOCTYPE html>.
3. Normalized every HTML page to exactly one canonical URL.
4. Added/normalized JSON-LD structured data and BreadcrumbList coverage across the site; repaired malformed legacy JSON-LD blocks.
5. Added visible breadcrumbs to pages that lacked them.
6. Added accessible names to previously unlabeled form controls without replacing existing explicit labels.
7. Standardized PDF Editor with the same primary DSUTILITY site navigation as the rest of the site while retaining its editor toolbar and save workflow.
8. Added PDF Editor related-tools/related-reading content where the live audit had exposed an empty section state.
9. Added static security headers via _headers: X-Content-Type-Options, Referrer-Policy, Permissions-Policy, HSTS.
10. Corrected privacy wording so claims describe local processing for supported workflows rather than implying that the entire site makes no network requests.
11. Removed production-facing legal-page OWNER placeholders without inventing a legal entity, address or jurisdiction.
12. Replaced the Resume Maker and Marriage Biodata Maker print-based PDF action with actual client-side PDF generation using html2canvas + jsPDF, including multi-page slicing for long previews.
13. Unified Home Search and All Tools search matching around the same scoring/alias logic; removed an accidental sparse-array hole from the fallback tool catalogue.
14. Reworked the “Why Your PDFs Should Never Leave Your Device” article to remove unnatural keyword-led sentences and make the privacy explanation technically precise and human-readable.
15. Reduced repeated generic paragraphs in affected guides where the same long text appeared across multiple pages.
16. Grammar Checker was NOT reintroduced; source residual scan remains clean.
